# Pulse — Windows

Download **[Pulse-Setup.exe](https://github.com/adamworkspace-09/pulse-releases/releases/latest/download/Pulse-Setup.exe)** and run it.

Already installed? Pulse updates itself (≈5 MB), or run **[Pulse-Update.cmd](https://github.com/adamworkspace-09/pulse-releases/releases/latest/download/Pulse-Update.cmd)**.

Android: **[Pulse.apk](https://github.com/adamworkspace-09/pulse-releases/releases/download/android/Pulse.apk)** — then updates from inside the app.

Pulse updates itself: when a new version is out, a "Redémarrer" button appears in the bottom-right corner.

> Windows may show "Windows protected your PC" the first time (the app isn't code-signed): click **More info → Run anyway**.
